# GOOD BYE BAD HALLOWEEN

「ハロウィン目的で渋谷に来ないで！」

渋谷駅からスクランブル交差点を渡って道玄坂へ向かってくる人の中から、**仮装した人だけ** をハリセンで成敗する、縦型のブラウザミニゲームです。本物のお化けと普通の人は見逃します。

人は奥（約34m先）から小さく現れ、近づくほど大きく見えます（3Dカメラの透視投影。Three.js は使わず Canvas 2D で描画）。見分けやすさのため、人物は実際の遠近より1.5倍大きく描いています（`personScale`）。重なりを減らすため、規制線のところでは4本のレーンに分かれて歩きます。プレイヤーは道玄坂の入口に立ち、渋谷駅の方を向いています。背景は渋谷駅（ハチ公口）、高架を走る山手線、駅の上の高層タワー、ハチ公広場（かぼちゃの帽子のハチ公像）、交差点に面したビルのビジョン、スクランブルの斜め横断歩道です。

タイトルは「GOOD BYE BAD HALLOWEEN」、slug は `goodbye-bad-halloween` です。公開URLは https://game.chozo.net/goodbye-bad-halloween/ です。

タイトル画面では、仮装した人＝タップで成敗、本物のおばけ・普通の人＝見逃す、を見本の絵とバッジで示しています。

## 遊び方

- 仮装した人をタップ → 成敗（仮装が脱げて、中からただの大学生が出てくる）
- 本物のお化け・普通の人は叩かずに通す
- 見分け方：**影があるのは人間**。本物のお化けには影がない
  - 仮装そっくりの本物（ドラキュラ・ジャック・オ・ランタン・魔女・フランケン・化け猫・ミイラ）：影がない、目が強く光る（かぼちゃは目の穴が光る）、足を動かさず滑ることがある。リプレイで本物の証拠として示すのはこの3つと、昔ながらの幽霊の「足がない・透けている」だけで、靴やしっぽなど仮装でも真似できるものは証拠にしない
  - 昔ながらの幽霊（白装束・シーツ・落ち武者）：足がなく、透けて浮いている
  - 仮装した人：影がある、スニーカー、値札・激安の袋・お酒の缶の小物
- ミスは3種類。3回でゲームオーバー
  - 本物のお化けを叩いた（祟られた）
  - 普通の人を叩いた（苦情）
  - 仮装した人を規制線の先（道玄坂）へ通した（見逃し）
- 時間制限なし。成敗した人数で称号が決まる

| 成敗した人数 | 称号 |
|---|---|
| 0〜19人 | 初心者 |
| 20〜39人 | ビギナー |
| 40〜59人 | 中級 |
| 60〜79人 | ベテラン |
| 80〜99人 | 上級 |
| 100〜119人 | 師範 |
| 120〜149人 | 伝説級 |
| 150〜199人 | 神話級 |
| 200人〜 | AI級 |
- 当たり判定は、画面に描かれている形そのもので行う。重なっているときは、指の下で見えている人（一番手前）に当たる。誰の上でもないときは、7px 以内で一番近い人に当たる（`src/game.js` の `HIT_R`）

## ミスのリプレイ

ミスすると、その場でリプレイが流れます（ハリセンが当たるところまで 0.4 秒進めてから開始）。

1. ミスの約1.8秒前から、0.5倍速のスローで対象にズームしながら再生する。見出しは「ミス！ 何がダメだった？」で、答えは伏せる
2. ミスの直前の姿で止め、「本物のドラキュラでした」「シーツおばけの仮装を見逃した」などの答えと、目印（影がない・目が光っている・スニーカー・値札など）を矢印で順番に示す
3. 約2.8秒で自動的に再開する。リプレイ中はどこをタップしてもスキップできる
4. 再開するときは交差点の人を全員消し、「再スタート！」と出して、まっさらな状態から始める（最初の人は0.8秒後に現れる。`REPLAY.restartDelay`）

ミスが続けて起きたときは順番に再生し、3回目のミスはリプレイのあとにゲームオーバーになります。

ゲームオーバー後の結果画面では、ミスが「本物のジャック・オ・ランタンを叩いた」のような一覧で並びます。タップするとそのミスのリプレイをもう一度見られます（タップか自動で結果画面に戻る）。目印の文言は `src/replay.js`、再生の秒数やズームは `src/game.js` の `REPLAY` で変えられます。

## 難易度

成敗した人数が `levelEvery`（6人）増えるごとにレベルが上がり、次が変わります（全20段階）。レベルが上がったことは、左上の「Lv」表示と効果音で知らせます（画面の中央には文字を出しません。人が多い場面で邪魔になるため）。

- 歩く速さ、出現の間隔、同時に歩く人数
- 幽霊っぽい仮装（シーツ・白装束・落ち武者）の割合
- その仮装の裾が足を隠す度合い（最後は靴先だけ見える）
- 本物のお化けのうち仮装そっくりのものの割合、滑らずに歩く割合、目の光の強さ
- 昔ながらの幽霊の透け具合、人魂の有無（Lv3 以降は人魂なし）

調整値と称号はすべて `src/config.js` にあります。

## BGM

音源ファイルは使わず、`src/audio.js` で合成しています。ポップで明るい8小節のループで、王道進行（F–G–Em–Am–F–G–C）の上にドラム・ベース・裏拍のコード・メロディを重ねています。2周目は終わり方を変えています。

- プレイ開始で流れ、ゲームオーバーとタイトルに戻ったときに止まる
- リプレイ中は音量を下げる
- レベルが上がるごとにテンポが少し速くなる（Lv1 は 136 BPM、最大 156 BPM）
- 右上の 🔊 で効果音といっしょに消せる
- 音量・テンポは `src/audio.js` の `BGM` で変えられる

## 起動

```sh
npm install
npm run dev      # http://localhost:5173/
npm run check    # 構文チェック
npm run e2e      # ヘッドレス Chrome で動作確認（スクリーンショットは shots/）
npm run build    # 公開用ファイルを dist/goodbye-bad-halloween/ に書き出す
npm run deploy   # build して Cloudflare Workers に公開する
npm run ogp      # OGP 画像 public/ogp.png（1200×630）を作り直す（dev サーバー起動中に実行。画像には公開URLが入る）
npm run promo    # 告知動画を ../video/ に書き出す（下の「告知動画」）
npm run catalog  # 仮装・普通の人・本物のお化けの一覧画像を docs/patterns/ に書き出す（dev サーバー起動中に実行）
```

`npm run e2e` は判定・ゲームオーバー・リトライ・画面サイズを確認し、次のボットの成績も表示します。

- `none`：何もしない
- `all`：全部叩く
- `perfect`：仮装だけ叩く
- `human`：反応0.9秒、幽霊っぽいものを8%で見間違える

## OGP 画像

`public/ogp.png` は、実際のゲーム画面（成敗の瞬間）にタイトル・キャッチコピー・遊び方（仮装は成敗、本物のおばけと普通の人は見逃す）を重ねたものです。左下に公開URL（game.chozo.net/goodbye-bad-halloween/）を入れています。`index.html` には `og:image` などのメタタグを絶対URLで入れています。

## 告知動画

`npm run promo` で、縦型 1080×1920・約30秒の告知動画を作ります。実際のゲームをヘッドレス Chrome で1コマずつ撮り、字幕を重ねて MP4 にします。BGM はゲームの合成 BGM（`src/audio.js`）を、効果音といっしょに同じ時計で書き出しています（音量は -14 LUFS に調整）。

- 出力: `../video/goodbye-bad-halloween-promo.mp4`、表紙 `-promo-cover.jpg`、2秒おきの一覧 `-promo-sheet.jpg`（動画はリポジトリに含めない。途中ファイルは `../video/work/`）
- 構成（`tools/promo/scenario.js`）: 仮装を次々に成敗（スロー）→ タイトル → Lv1・Lv7・Lv15 でそれぞれ1〜2人を成敗（等速）→ 本物のおばけ（ドラキュラ）を成敗してしまいミス、リプレイで答え合わせ → エンドカード。1回のプレイを始め直さずに撮るので、BGM は最後まで途切れない
- `PROMO_EVERY=15 npm run promo`: 15コマおきに撮って構成だけ確認する（`-promo-preview.jpg`）
- `PROMO_ENCODE_ONLY=1 npm run promo`: 撮り直さずに音と MP4 だけ作り直す
- 撮影用の入口: `window.__game` の `manual` / `step` / `drainEvents` / `audio`（`capture` / `drain` / `resync` / `render`）。撮影中は音を鳴らさず呼び出しを記録し、書き出し時に OfflineAudioContext で同じ音を鳴らす
